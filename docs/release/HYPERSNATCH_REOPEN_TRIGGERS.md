# HyperSnatch Reopen Triggers

Date: 2026-03-22

## Valid Reasons To Reopen Work

1. Intentional proof-only effort to close or further narrow `PDG-01`.
2. Intentional proof-only effort to close or further narrow `PDG-02`.
3. Dependency/toolchain drift that creates a new truth problem.
4. Formal expansion-gate revisit with new evidence.

## Invalid Reasons To Reopen Work

1. Boredom.
2. Cleanup for its own sake.
3. Feature ideas without a new gate decision.
4. Version bump with no runtime delta.

## Boundary Reminder

- Reopen work only under explicit trigger conditions.
- Do not infer expansion readiness from freeze-state documentation.
